# Soma v0.97.0 Release Notes — "The Sunset Phase"

**Release Tag**: `v0.97.0`  
**Date**: 2026-10-06  
**Type**: Major Architectural Breaking Release  

---

## 1. Executive Summary

Soma `v0.97.0` represents **The Sunset Phase** — the scheduled culmination of the architectural bloat remediation plan initiated in `v0.96.0` and bridged in `v0.96.2`. In this release:
- All legacy shell installers and the entire legacy `enzymes/` directory (75 files) have been permanently purged from the codebase.
- Platform installations and lifecycle management are now 100% native Python via the new polymorphic `PlatformAdapter` registry (`Gemini`, `Claude`, `Copilot`, `Kiro`, and `Mcp`).
- Hardcoded lookup tables (`SOURCE_TO_TEST_MAP`) have been completely deleted from `immune_system/verification/checkpoint_checks.py` in favor of fully dynamic test candidate discovery.
- A 1:1 mirrored test package architecture (`tests/soma_core/`, `tests/soma_cli/`, `tests/soma_mcp/`, `tests/soma_sdk/`, `tests/immune_system/`) has been established with pytest `importlib` isolation.
- Soma remains 100% zero-dependency at runtime (`dependencies = []`).

---

## 2. Breaking Changes

### Purge of Legacy `enzymes/` Directory
The `enzymes/` directory (75 shell and python scripts) has been permanently deleted from git tracking and package distribution manifests.
- **Removed**: Direct script invocations (`python enzymes/cell_*.py`, `sh enzymes/*.sh`).
- **Replacement**: Use the unified CLI entrypoints: `soma <command>` or direct `soma_core` / `soma_cli.handlers` Python APIs.

### Elimination of Shell & PowerShell Installers
Legacy scripts `install/install.sh`, `install/install.ps1`, `install/uninstall.sh`, and `install/uninstall.ps1` (4,277 LOC) have been permanently deleted.
- **Replacement**: Use `soma install --platform <platform>` and `soma uninstall --platform <platform>`. Supported platforms: `gemini`, `claude`, `copilot`, `kiro`, and `mcp`.

---

## 3. Key Enhancements & New Components

### 1. Polymorphic Platform Adapters (`soma_cli.platforms`)
- Concrete implementations of `PlatformAdapter(ABC)`:
  - `GeminiAdapter`: Configures `.gemini/` rules, skills, and settings.
  - `ClaudeAdapter`: Configures `.claude/` instructions and MCP entries.
  - `CopilotAdapter`: Manages `.github/copilot-instructions.md`.
  - `KiroAdapter`: Manages `.kiro/` steering rules.
  - `McpAdapter`: Manages Claude Desktop and stdio MCP server registrations.
- Native filesystem operations without invoking shell or PowerShell subprocesses.

### 2. Fully Dynamic Test Discovery & Mirrored Structure
- Deleted legacy `SOURCE_TO_TEST_MAP` dictionary from `immune_system/verification/checkpoint_checks.py`.
- Dynamic candidate resolution intelligently discovers:
  - Canonical mirrored paths: `tests/<pkg>/.../test_<stem>.py`.
  - Subpackage suites and platform adapters (`test_cli_handlers.py`, `test_platform_adapters.py`).
  - Standard behavioral and root suites (`test_<stem>.py`).
- 1:1 mirrored test suites covering all 83 core modules across `soma_core`, `soma_cli`, `soma_mcp`, `soma_sdk`, and `immune_system`.
- Pytest configured with `addopts = "--import-mode=importlib"` ensuring complete test isolation across duplicate test basenames.
