# Privacy Policy

This Privacy Policy explains how Soma handles your data, source code, and telemetry. Soma operates on a local-first, privacy-conscious architecture.

## 1. Soma MCP Server (Fully Local & Air-Gapped)

The `soma_mcp` server provides Model Context Protocol (MCP) tools to LLM-enabled IDEs (e.g., Claude Desktop, Antigravity, Cursor).

**Privacy Guarantees**:
- **Offline & Local**: The MCP server is fully local. It makes zero outbound network requests to the internet.
- **Local Analysis**: Tools analyze files, git diffs, cell health, and security rules strictly on your local filesystem using local heuristics and subprocess calls.
- **No Third-Party Telemetry**: No source code, project metadata, or governance reports are ever collected or transmitted to external servers by the MCP server.

*Note: Your LLM IDE client connecting to the MCP server sends user prompts and returned tool outputs to its configured cloud inference provider (e.g., Anthropic, OpenAI, Google) in accordance with that client's privacy policy.*

## 2. Soma CLI (Opt-In Cloud Features)

The Soma CLI includes optional natural-language features (such as natural-language cell authoring via `enzymes/inference_provider.py`).

**Privacy Guarantees**:
- **Strictly Opt-In**: Cloud inference is only invoked when you explicitly execute an LLM-assisted CLI command.
- **Direct Provider Connection**: Requests are sent directly to your chosen provider (Google Gemini, Anthropic Claude, or OpenAI) using your own API keys. Soma has no intermediary servers.
- **Zero Background Transmission**: The CLI never transmits code or telemetry in the background.

## 3. Data Storage & Local Boundaries

All governance data generated by Soma is stored locally in the `.soma/` directory within your workspace:
- **Receipt Tokens**: Execution receipts (`secrets.token_hex(32)`) are held ephemerally in server memory and automatically expire; they are never persisted to disk or transmitted externally.
- **Telemetry & Manifests**: Local telemetry signals and signed cell manifests (`manifest.json`) remain strictly local to your workspace.
- **Excluded Secrets & Telemetry**: Sensitive files including HMAC signing keys (`.soma/keys/manifest.key`) and human-in-the-loop developer insights (`.soma/human_insights.jsonl`) are explicitly excluded from version control via `.gitignore` to prevent accidental commits and data leakage.
- **User Ownership**: You maintain full ownership and control over all data in `.soma/`. Deleting the `.soma/` directory completely removes all local Soma records.
