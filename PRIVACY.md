# Privacy Policy

This Privacy Policy explains how Soma handles your data. The Soma toolset operates in a dual-scope architecture regarding data privacy.

## 1. Soma MCP Server (Fully Local)

The `soma_mcp` server provides tools to LLM IDEs (e.g., Claude Desktop, Antigravity, Cursor) via the Model Context Protocol (MCP).

**Privacy Guarantee**: The MCP server is **local-first**.
- Most tools (like scanning and rule evaluation) operate entirely locally and do **not** make external network calls.
- The exception is `soma_propose_change` (and related LLM-powered audits), which may transmit the proposed source code and relevant `.oracles` rules to external inference providers to perform advanced checks.
- No telemetry or background tracking is sent to third-party servers by the MCP server itself.

*Note: The LLM IDE client connecting to the MCP server may send prompts containing the MCP server's output to its respective cloud provider (e.g., Anthropic or OpenAI) in accordance with the IDE's own privacy policy.*

## 2. Soma CLI (Opt-In Cloud Features)

The Soma Command Line Interface includes features (like natural language cell generation) that rely on external LLM inference providers (`inference_provider.py`).

**Privacy Guarantee**: These features are **strictly opt-in**.
- When you explicitly invoke an LLM-powered CLI command, Soma will transmit the necessary prompts (which may include snippets of your code or git diffs) to the configured inference provider (Gemini, Anthropic, or OpenAI).
- You control which provider is used via your environment variables.
- The CLI will never send data to these providers in the background. Network calls are only made when you actively run an LLM-dependent command.

## 3. Data Storage

All governance data, cell definitions, fitness reports, and HMAC-SHA256 manifests generated by Soma are stored locally in the `.soma/` directory within your workspace. 
- You maintain full ownership and control over this data.
- If you wish to delete all Soma data, simply remove the `.soma/` directory.
